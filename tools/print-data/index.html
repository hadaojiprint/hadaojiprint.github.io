背景を除去する

閲覧中はプレビュー上でもスクロールできます。

ブラシ・表示の詳細設定

PNG・JPEG・WebPに対応

確認用の背景色は、保存するPNGには入りません。

四隅から背景色を推定します。違う色の場合は「背景の色を拾う」で指定してください。画像全体から指定色を除去します。文字の内側や離れた部分も対象です。「消す」ではタップした色を一括削除できます。

数字を上げると、指定色に近い部分も消します。消しすぎたら「ひとつ戻す」か「戻す」で復元。自動除去は現在の状態に追加されます。

STEP 01 / UPLOAD

使いたいデザインを選ぶ

35MB・1200万画素まで。大きな画像は、無断で縮小せず読み込みを止めます。HEICはPNGまたはJPEGに変換してください。

STEP 03 / PRINT SIZE

実寸とPPIを決める

縦横比は固定。どちらかを変えると、もう一方も合わせます。余白を除く設定は、残っているデザイン全体の範囲を使います。

PPIは実寸に対する画素の密度です。元画像を拡大しても、細部が正確に増えるわけではありません。入稿先の指定を優先してください。

まずは画像を選んでください。
