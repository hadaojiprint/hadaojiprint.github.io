BEGINNER'S QUEST

オリジナルTシャツは
1枚から作れる？

作れます。1枚だけの場合に向いている方法や、注文前に準備するものを攻略していきましょう。

友だちへのプレゼントに、
1枚だけ作りたい！

MISSION MAP

1. 結論 2. 方法を選ぶ 3. 料金の考え方 4. データ準備 5. 失敗を防ぐ GOAL
STAGE 1

結論：1枚からでも作れます

オリジナルTシャツは、業者やプリント方法を選べば1枚から制作できます。プレゼント、試作品、自分用のウェアなど、小ロットでも問題ありません。

HADAOJI'S HINT

1枚なら、版を作らないDTFプリントやインクジェットプリントが向いているよ！

STAGE 2

1枚制作に向いている方法

おすすめ

DTFプリント

専用フィルムに印刷し、熱でウェアへ圧着します。フルカラーや細かい絵柄にも対応しやすい方法です。

  • フルカラー対応
  • 濃色TシャツもOK
  • 1枚から作りやすい
写真向け

インクジェット

Tシャツへインクを直接吹き付けます。写真やグラデーションのあるデザインと好相性です。

  • 自然な風合い
  • 写真表現に強い
  • 素材に条件あり
枚数向け

シルクスクリーン

色ごとに版を作ってインクを刷ります。枚数が増えるほど1枚あたりを抑えやすい方法です。

  • 発色が良い
  • 耐久性が高い
  • 1枚では割高
STAGE 3

料金は何で決まる？

料金は「Tシャツ本体」「プリント方法」「プリントサイズ」「印刷箇所」「デザイン調整」の組み合わせで変わります。

01ボディ素材・厚み・サイズ
02プリント方法・大きさ・色数
03加工箇所胸・背中・袖など
04データ背景透過・解像度調整

※正確な金額は、ウェア・デザイン・希望サイズを確認してからの見積もりになります。

STAGE 4

準備するもの

✓

使いたい画像PNG・JPEG・PDFなど。スマホ画像でも相談可能です。

✓

希望するTシャツ色、サイズ、素材、着用する場面を決めます。

✓

プリント位置左胸、中央、背中など、大まかな希望で大丈夫です。

BOSS STAGE

よくある失敗を防ぐ

!画像が小さい拡大すると輪郭がぼやける場合があります。
!背景が白い白い四角も一緒に印刷されることがあります。
!位置が曖昧プリントの幅と位置を事前に確認しましょう。
