HCGはデータの準備、HPSはウェアの見え方を確認する道具

「背景を消したい」「胸に何cmで載せるといいだろう」「前と後ろで見え方を確かめたい」。そんなとき、まず自分でイメージを作ってみられるように、ハダオジでは2つのツールを用意しました。

HCG（ハダオジ クリッピングジェネレータ）は、画像の背景と出力サイズを整える道具。HPS（ハダオジ プリントシミュレーター）は、ウェアに画像や文字を載せて配置を考える道具です。どちらもブラウザで操作できます。

完成まで全部を自分で決める必要はありません。「ここまではできたけれど、これで印刷できる？」という段階で相談するためにも使ってください。

HCGの操作①：画像を読み込み、背景を除去する

  1. 「画像ファイル」から画像を選択。PNG・JPEG・WebPに対応します。まず「サンプルで試す」でも操作できます。
  2. プレビュー下の「消す」を選び、消したい色をタップ。タップした場所だけでなく、画像内の同じ色をまとめて除去します。文字の穴や、離れた部分も対象です。
  3. 近い色が残るときは「色の許容範囲」を調整。数字を上げると近い色も削除対象になります。背景色を指定して「背景を自動除去」を押す操作もできます。
  4. 「加工後」と「元画像」を切り替えて確認。消しすぎたら「ひとつ戻す」。細かい部分は「ブラシで消す」「戻す」で調整します。
同じ色を残したい場所にも注意。

白背景を消すと、白いイラストの一部も一緒に消えることがあります。同色を一部だけ残す場合は、ブラシで背景を消すか、「戻す」で必要な部分を復元してください。複雑な写真から人物を自動で判別するAI切り抜き機能ではありません。

市松模様は透明部分の表示です。確認用の白・黒背景は、保存するPNGには入りません。ブラシや表示の設定は「ブラシ・表示の詳細設定」を開いて調整します。

スマホでは、編集操作をする間だけプレビュー内のスクロールを止めます。「閲覧・スクロール」に戻せば、画像の上でもページをスクロールできます。

HCGの操作②：実寸とPPIを指定し、PNGを保存する

  1. 「透明な余白を除いて…」の設定を確認。オンなら、残っているデザイン全体の範囲を基準に実寸を指定します。オフなら、元画像の余白を含むサイズが基準です。
  2. 「横幅（cm）」または「縦幅（cm）」を入力。縦横比は固定され、片方を変えるともう片方が連動します。
  3. PPIを150・300・600から選択。300 PPIは出発点の目安です。入稿先に指定があればそちらを優先します。
  4. 出力画素数と画質の案内を確認して「指定サイズのPNGを作成」。完成後、「PNGをダウンロード」から保存します。対応する端末では「画像ファイルを共有・保存」も使えます。

PPIは、実寸に対して何画素あるかという密度です。高いPPIで書き出しても、小さな画像の細部が復元されるわけではありません。拡大が必要な場合は画面に案内が出ます。元画像の画質に迷ったら、低解像度画像のプリントの考え方も参考にしてください。

PNGにはPPIの情報も埋め込みますが、写真アプリや送信先の処理で書き換わる場合があります。入稿用はファイルとして保存し、「横幅25cmで印刷したい」のように実寸も伝えると確認がスムーズです。

HPSの操作①：ウェアを選び、画像・文字を配置する

  1. HPSを開き、「画像を追加」でデザインを読み込み。HCGで保存した透過PNGを選べます。すでに透過データがある場合はHCGを通さず、そのままHPSで使えます。
  2. ウェアとカラーを選択。Tシャツ・ロンT・ポロシャツ・パーカー・トレーナーを切り替えられます。実際に選ぶ商品のサイズスペックが分かる場合は、平置き身幅・身丈も合わせます。
  3. プレビューの「前面」「背面」を切り替え。それぞれに画像を追加し、位置とサイズを考えます。
  4. 画像をドラッグして位置を調整。プレビュー内の横幅・縦位置・回転の設定でも調整できます。複数のデザインは、操作したい画像を選択してから動かします。
  5. 文字を加えるなら「文字を追加」。フォント・カラー・文字の枠線・アーチを調整できます。不要な画像や文字は、選択して「選択画像を削除」で取り除きます。

操作する間のスクロール停止はプレビュー内だけです。文字の詳細設定や、画像の外側からはページをスクロールできます。

着用イメージでは、平置き身幅と正面から見える幅は同じではありません。HPSの「着用時の厚み・奥行き」は、この違いを考えるための推定設定です。人体や商品の形を厳密に再現するものではないので、実際に着たときの見え方は変わります。Tシャツのサイズ表の見方も確認してください。

HPSの操作②：前面・背面のイメージを保存して相談する

  1. 「前面・背面の保存用画像を表示」を押す。左が前面、右が背面の画像を生成します。
  2. 画像を保存。iPhoneでは「写真に保存」から共有メニューの「画像を保存」を選びます。ボタンが出ない場合は表示画像を長押しして保存する方法もあります。ファイルとしてのダウンロードも選べます。
  3. LINEを開き、保存した画像を添付。希望の枚数・ウェア・色・納期と一緒に送ってください。画像はLINEへ自動送信されません。
HPSの保存画像と、プリントする元データは別です。

HPSの画像は位置やバランスを共有する完成イメージです。製造用には、HCGで整えたPNGや元のデザインデータも別に送ってください。画面のスクリーンショットだけでは、十分な画質を確保できない場合があります。

位置を細かく指定したい場合は「襟下から何cm」「横幅何cm」のように寸法も添えてください。迷う場合は「この見え方に近づけたい」で大丈夫です。プリントサイズと位置の決め方で、考える順番を紹介しています。

使う前に知っておきたいこと

  • 現在はプロトタイプです。不具合や気になる点は店長までお知らせください。
  • 画面の色や配置はイメージです。実際の生地色・着用時の見え方・加工できる範囲を保証するものではありません。
  • 画像の処理はブラウザ内で行います。画像を加工のためにサーバーへ送る仕組みではありません。ページアクセスやボタン操作はアクセス解析の対象です。
  • 大きな画像には上限があります。HCGの読み込みは35MB・1200万画素・一辺9000pxまで。出力は2400万画素・一辺12000pxまでです。HEICはPNG・JPEGなどへ変換してください。
  • 保存先は端末やブラウザで変わります。保存したファイルが見つからないときは、ブラウザのダウンロード一覧やファイルアプリを確認してください。

よくある質問

2つのツールを必ず両方使いますか？

必要な方だけで大丈夫です。背景やサイズを整えるならHCG、配置だけ見たいならHPSを使います。

白い文字の中に残った黒も消せますか？

HCGの「消す」で黒をタップすると、離れた場所や文字の内側も含めて対応色を除去できます。残したい黒も対象になるため、加工後の画像を確認してください。

HCGのPNGをHPSへ自動で送れますか？

現在は自動転送ではありません。PNGを保存してからHPSの「画像を追加」で読み込みます。

HPSの通りにプリントできますか？

商品やサイズ、縫い目、加工方法によって実現できる範囲は変わります。イメージと元データを送っていただければ、一緒に方法を確認します。

まず試して、難しいところは一緒に考えましょう

自分でデータを整え、ウェアに載せてみると、やりたいことが少し具体的になります。うまく切り抜けない、プリントが大きすぎる気がする、色の組み合わせで迷う。そんなところからの相談も歓迎です。

ハダオジの方針は「共に見つける。共に創る。」。ツールで全部を決めてもらうのではなく、希望を共有しやすくするための道具として使ってもらえたらうれしいです。
