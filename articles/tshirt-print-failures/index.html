QUEST START

失敗の多くは、注文前の確認で防げます

オリジナルTシャツの失敗は、プリント作業だけが原因とは限りません。元画像の状態、仕上がりサイズの伝え方、ボディの素材、枚数に合わない加工方法など、制作前の小さな認識違いから起こります。

ここでは、ハダオジ店長とゆうが10の失敗ダンジョンを攻略。各項目で「何が起きるか」と「どう伝えれば防げるか」をセットで確認します。

HADAOJI'S HINT

分からないことを全部決めてから相談する必要はありません。用途・枚数・希望日・使いたい画像が分かれば、一緒に整理できます。

STAGE 1 / PIXEL TRAP

失敗1：画像を大きくしたら粗くなった

LINEで送ったスクリーンショットや、SNSから保存した小さな画像は、画面ではきれいに見えても大きなプリントでは輪郭がギザギザになることがあります。小さい画像を引き伸ばしても、元にない細部は増えません。

MISS小さな画像をそのままA3へ拡大文字や細い線ほど、ぼやけや欠けが目立ちます。
CLEAR元データを探し、実寸で確認AI・PDF・高解像度PNGが理想。ない場合は希望サイズを先に伝えます。

詳しくは：低解像度の画像でもプリントできる？

STAGE 2 / SIZE MAZE

失敗2：思ったより小さい・位置が低い

「胸に大きめ」「背中の真ん中」だけでは、完成像が人によって変わります。同じ横25cmでも、SサイズとXLサイズでは見え方が違います。配置はプリント幅と、襟や脇からの距離で共有するとズレを減らせます。

MISSスマホの合成画像だけで決定画面上の比率と実際のcmが一致していないことがあります。
CLEARA4用紙をTシャツへ置くA4は21×29.7cm。実寸の紙を当て、正面から写真を撮ると伝わります。

詳しくは：プリントサイズと位置の決め方

STAGE 3 / COLOR MIRAGE

失敗3：画面で見た色と仕上がりが違う

スマホやモニターは光で色を見せますが、Tシャツはインクと生地の反射で見えます。画面の明るさ、ボディ色、素材、白インクの下地、加工方法により、蛍光感や淡い色、黒に近い階調は印象が変わります。

MISS画面の色が完全再現されると思う端末ごとにも見え方が異なり、同じRGB値でも仕上がりは別物です。
CLEARボディ色と色見本を先に共有色が重要な案件は、近い色番号・現物写真・試作の要否まで相談します。
STAGE 4 / METHOD FORK

失敗4：枚数とデザインに合わない方法を選んだ

加工方法には向き不向きがあります。少数のフルカラーにシルクスクリーンを選ぶと製版代の割合が大きくなり、同じ1色を多数作るのにDTFを選ぶと、条件によっては単価や風合いで不利になることがあります。

MISS方法名だけを先に決める価格だけでなく、色数・枚数・生地・納期との組み合わせが重要です。
CLEAR用途と希望の仕上がりから選ぶ少数フルカラーはDTF、多数の同柄・少色はシルクを出発点に比較します。

詳しくは：シルクスクリーンとDTF、どちらを選ぶ？

STAGE 5 / SEAM WALL

失敗5：襟や縫い目に近く、プリントが欠けた

熱プレスや印刷は、できるだけ平らな面で行います。襟、脇、ポケット、ファスナー、厚い縫い目の近くは圧力が均一になりにくく、欠け・圧着不足・段差の跡が起こることがあります。袖をぐるりと一周するような配置も、設備やボディ形状によってはできません。

MISS完成図だけで加工位置を決める見た目では入っていても、縫製やプレス機の構造で加工できない場合があります。
CLEAR縫い目から余白を取る希望位置を写真で示し、加工可能範囲と安全な余白を制作側に確認します。
STAGE 6 / BODY SELECT

失敗6：生地・サイズ・洗濯後の印象が想定外

綿Tシャツとドライ素材では、肌触り・光沢・透け感・プリントのなじみ方が違います。同じ表記サイズでも品番ごとに身幅や丈は異なり、乾燥機などの扱いで縮みやプリントへの負担が生じることもあります。

MISSサイズ名と商品写真だけで選ぶ「普段MだからM」で決めると、シルエットが想像と違うことがあります。
CLEAR実寸・用途・洗濯方法を確認身幅と身丈を手持ちの服と比較し、スポーツ用か普段着かも伝えます。
STAGE 7 / WHITE BOX

失敗7：画像の白い背景まで印刷された

画像の背景が白く見えていても、透明とは限りません。JPEG画像やスクリーンショットは基本的に背景を持つため、濃色Tシャツへプリントすると、デザインの周囲に白い四角がそのまま出ることがあります。

MISS白背景を透明だと思って入稿白い画面上では違いが見えず、完成後に初めて気づくことがあります。
CLEAR市松模様と透過PNGを確認背景を残すデザインか、輪郭で切り抜くかを注文前に伝えます。
STAGE 8 / DETAIL TRAP

失敗8：細い線や小さな文字が潰れた

画面を拡大すれば見える細線や小文字でも、インク・フィルム・生地には再現できる限界があります。特にかすれた書体、細い抜き線、複雑な装飾は、縮小すると潰れたり消えたりしやすくなります。

MISS画面の拡大表示だけで判断実際のプリントサイズへ縮めると、線と線の隙間がなくなる場合があります。
CLEAR実寸表示して線を太くする小さな文字は大きくし、細部は省略して読みやすさを優先します。
STAGE 9 / RIGHTS GATE

失敗9：権利のある画像で制作できなかった

インターネットで見つけた画像、企業やチームのロゴ、漫画・ゲームのキャラクター、著名人の写真などは、自由にTシャツへ使えるとは限りません。個人で着る目的でも、制作会社が権利確認をできない場合は注文を受けられないことがあります。

MISS検索画像をそのまま送る画像を保存できることと、プリントへ利用できることは別です。
CLEAR自作・許諾済み素材を用意権利者の許可がある場合は、その確認方法も制作側へ共有します。
BOSS STAGE / TIME LIMIT

失敗10：直前の変更で希望日に間に合わなかった

Tシャツの取り寄せ、データ確認、見積もり、入金、プリント、検品、発送にはそれぞれ時間が必要です。注文後に枚数・サイズ・デザイン・加工位置が変わると、材料の再手配やデータの作り直しが発生し、当初の納期に間に合わなくなることがあります。

MISS使用日の直前まで仕様が未確定在庫切れや配送遅延が重なると、加工時間だけでは調整できません。
CLEAR使用日から逆算して早めに確定変更の可能性も先に伝え、余裕を持った納品日を相談します。
FINAL CHECK

注文前に送ると失敗を減らせる6項目

01使いたい画像
02枚数とサイズ内訳
03Tシャツの色・素材
04プリント幅と位置
05使う日・希望納期
06重視したい色や風合い
YUU'S CHECK
